# 통합 검색 평가와 하이브리드 검색
> 현재 기준 안내(2026-08-10): 파이프라인 완성 후 전체 자동 테스트는 148개 통과했다. 본문에 더 작은 테스트 수가 있으면 해당 기능을 만들던 당시의 기록이다. 최신 전체 성능은 [독립 평가 보고서](HOLDOUT_EVALUATION.md)를 참고한다.


## 평가 목적

수강편람 한 개가 아니라 2026년 학사·장학 통합 인덱스에서 정답 근거를 안정적으로 찾는지 측정한다. 눈으로 몇 개 검색하는 대신 질문별 정답 문서 ID와 핵심 문구를 고정했다.

## 평가셋

- 파일: `eval/unified_questions.jsonl`
- 질문: 21개
- 분야: 수강신청 3, 학적 5, 졸업 4, 등록금 2, 학점교류 2, 장학 5
- 정답 조건: 기대 부모 문서 ID와 모든 핵심 문구를 함께 만족하는 청크
- 검색 대상: 신뢰 인덱스 10,663개 청크
- 평가 범위: Top 5, 후보 300개

실행:

    .venv/bin/sejong-evaluate-unified

## 최종 검색 규칙

1. E5 의미 벡터 순위와 TF-IDF 키워드 순위를 2:1 RRF로 결합
2. 이미 벡터·본문 후보가 된 청크에만 제한된 제목 일치 보너스 적용
3. 질문의 학년도·학기와 문서 메타데이터 일치 반영
4. 분야 키워드와 공지 카테고리 일치 반영
5. 목적별 query expansion
   - 신청+언제/기간 → 신청기간
   - 학점교류+평점 → 총 평점평균
   - 지급+언제/일정 → 현금지급일정
   - 서류/가져가다 → 제출서류
6. 확장한 행정 용어가 실제 공식 공지 본문에 있을 때 요약 근거 우선
7. 첨부가 상위에 검색되면 부모 공지 본문도 함께 승격
8. 질문 기간과 일치하는 현재 후보가 있으면 같은 문서군의 historical 문서만 감점
9. 사업명이 없는 일반 장학금 질문에는 명확화 경고 표시

## 실험 중 폐기한 규칙

- 제목 순위를 1.5배로 직접 합산: 같은 문서의 모든 첨부 페이지가 상위를 점유해 회귀
- 모든 `언제` 질문에 일정·마감 추가: 등록금 납부 확인 같은 다른 의도를 오염
- current 문서의 모든 청크에 큰 보너스: 같은 문서 내부 청크가 결과를 독점

평가 하락을 확인한 규칙은 최종 코드에서 제거했다.

## 해석과 한계

- 1.0은 이 21개 내부 질문에서 정답이 Top 5에 들어왔다는 뜻이다.
- 학교 전체 질문의 정답률이나 최종 Gemini 답변 정확도 100%를 의미하지 않는다.
- 평가 질문을 보며 규칙을 조정했으므로 별도의 미공개 holdout 평가가 필요하다.
- 일반적인 장학금 질문은 사업명·학기가 없으면 재질문해야 한다.
- 검색 상위 1위가 항상 가장 직접적인 근거는 아니므로 생성 단계에서 여러 근거의 제목·기간·품질을 비교해야 한다.
- 검토 인덱스는 이번 수치에 포함하지 않았다.

다음 단계는 최종 하이브리드 결과를 context builder와 Gemini에 연결하고, 검색 성공과 답변 생성 성공을 분리해 평가하는 것이다.
