# 하이브리드 검색 기준선
> 역사적 단계 기록: 이 문서는 개발 당시의 구현과 수치를 보존한다. 현재 상태와 실행 방법은 [프로젝트 README](../README.md) 및 [문서 지도](README.md)를 기준으로 한다.


## 목적

키워드 검색의 정확한 용어 일치와 벡터 검색의 의미 유사도를 결합해 단독 검색의 실패를 줄인다.

## 방식

- 벡터 검색: multilingual-e5-small cosine similarity
- 키워드 검색: 간단한 한국어 정규화가 포함된 TF-IDF 계열 점수
- 질의 확장: 제한적인 학생 표현 → 학교 문서 용어 매핑
  - `다시 듣다`, `다시 들으면`, `다시 수강` → `재수강`
  - `최고 성적`, `최대 성적` → `성적 제한`
- 결합: Reciprocal Rank Fusion(RRF)
- 후보: 각 검색 상위 100개
- 최종 반환: 상위 5개
- RRF 상수: 60

RRF는 서로 척도가 다른 cosine 점수와 키워드 점수를 직접 더하지 않고 각 검색 순위를 결합한다.

```text
RRF score = 1 / (60 + vector rank) + 1 / (60 + keyword rank)
```

질의 확장에는 정답인 `A0`를 넣지 않았다. 평가 정답을 검색어에 주입하면 실제 성능이 아니라 정답 누출을 측정하게 되기 때문이다.

## 결과

| 질문 | 벡터 검색 | 하이브리드 검색 | 판정 |
|---|---:|---:|---|
| 소프트웨어학과 졸업학점 | 관련 표 1위 | 관련 표 1위 | 유지, 입학년도 질문 필요 |
| 소프트웨어학과 최대 수강신청 학점 | 정확한 6쪽 3위 | 정확한 6쪽 1위 | 개선 |
| 재수강 성적 | A0 정답 1위 | A0 정답 1위 | 유지 |
| 과목을 다시 들으면 받을 수 있는 최고 성적은? | A0 정답 36위 | A0 정답 2위 | 크게 개선 |

우회 표현 질문의 하이브리드 1위는 같은 34쪽의 재수강 관련 내용이지만 A0 문장이 없는 chunk다. 따라서 페이지 단위 Hit@5는 성공이고 정확한 answer-chunk 기준으로는 rank 2다.

## 한계

- 질의 확장은 현재 소수의 수동 규칙뿐이다.
- 졸업학점은 입학년도에 따라 달라 질문에 조건이 없으면 하나의 답을 고를 수 없다.
- 표 안의 행과 열 관계를 일반 텍스트 임베딩만으로 완전히 보존하지 못한다.
- 네 질문만으로는 다른 학사 질문에 일반화된다고 판단할 수 없다.
- RRF 상수와 후보 수는 아직 체계적으로 튜닝하지 않았다.

## 다음 단계

최소 15개 평가 질문에 대해 기대 문서, 페이지, 정답 문구와 필수 조건을 사람이 기록한다. 이후 Hit Rate@5와 MRR을 자동 계산해 검색 변경 전후를 비교한다.
