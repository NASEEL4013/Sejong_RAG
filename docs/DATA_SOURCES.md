# 세종대학교 RAG 데이터 소스 카탈로그

> 최초 조사: 2026-08-09 · 최신 확인: 2026-08-10
> 상태: 2026년 학사·장학 공지와 첨부파일 수집 완료
> 원칙: 세종대학교 공식 공개 출처를 우선하며, 답변에 원문 URL과 적용 기준 시점을 표시한다.

## 조사 결론

정보는 상시 학사안내, 학기별 공지, 학과·학년도별 교과과정으로 나뉜다. 따라서 정보 영역, 문서 유형, 게시일, 적용 학기, 입학년도, 학과·전공을 메타데이터로 저장하고 검색 시 함께 필터링해야 한다.

### 확인된 게시판 구조

- 목록은 게시물 제목, 담당 부서, 등록일, 조회수와 첨부파일 존재 여부를 제공한다.
- 개별 게시물은 게시판 URL에 articleNo와 mode=view가 포함된 주소를 사용한다.
- 페이지네이션과 제목·내용·작성자 검색 기능이 있다.
- 본문과 첨부파일은 함께 수집하되 각각 별도 문서로 저장한다.
- 같은 공지의 첨부파일이 교체될 수 있으므로 파일명, 수집 시각, content_hash로 버전을 구분한다.
- 수강편람은 파일명 뒤 날짜가 내용의 기준일이 될 수 있어 attachment_version_date 필드가 필요하다.

### 대표 확인 문서

- 최신 확인 대상인 2026-2학기 수강편람 공지: https://www.sejong.ac.kr/kor/intro/notice3.do?mode=view&articleNo=891485&article.offset=0&articleLimit=10
- 학사공지 목록에서도 2026-2학기 수강편람과 첨부파일 존재가 확인됐다.
- 이전에 기록한 2026-1학기 공지는 퀵메뉴가 가리킨 과거 문서였으며 최신 자료 탐색 기준으로 사용하지 않는다.
- 같은 제목 또는 같은 학기의 게시물이 재등록·갱신될 수 있으므로 articleNo, 게시일, 첨부파일명과 content_hash를 비교한다.

## 초기 수집 범위

- 대상: 세종대학교 학부 재학생 전체
- 영역: 학교 공통 학사·장학·수강·졸업 규정과 학과별 교과과정·졸업요건
- 우선 학년도: 2026학년도
- 공식 공개 웹페이지와 웹페이지에 첨부된 PDF, HWP/HWPX, DOCX 등의 원문을 함께 수집
- 로그인 필요 페이지, 개인정보, 대학원 규정, 비공식 자료 제외
- 전체 학과 자료를 보존하되 소프트웨어학과를 첫 학과별 정확성 검증 사례로 사용

## 메타데이터 스키마 초안

| 필드 | 설명 |
|---|---|
| source_id, document_id | 소스와 문서 버전의 고유 ID |
| title, source_url | 공식 제목과 원문 주소 |
| source_type, category | 문서 유형과 정보 영역 |
| authority | 담당 부서 또는 게시 주체 |
| published_at, updated_at, collected_at | 게시·수정·수집 시각 |
| academic_year, semester | 적용 학년도와 학기 |
| admission_years, departments | 대상 입학년도와 학과 |
| student_types | 신입생, 재학생, 편입생, 복학생 등 |
| effective_from, effective_to | 효력 기간 |
| supersedes | 대체하는 이전 문서 ID |
| parent_document_id | 첨부파일이 연결된 원본 공지의 문서 ID |

| file_type, content_hash | 파일 형식과 변경 감지 해시 |
| attachment_filename | 서버가 제공한 실제 첨부파일명 |
| attachment_version_date | 파일명 또는 공지에서 추출한 첨부 버전 기준일 |
| review_status | unreviewed, verified, stale, conflict |

## 웹페이지와 첨부파일 처리 원칙

1. 공지 웹페이지에서 제목, 담당 부서, 게시일, 본문과 첨부 링크를 추출한다.
2. 각 첨부파일을 다운로드하고 PDF, HWP/HWPX, DOCX 형식에 맞는 로더로 텍스트를 추출한다.
3. 첨부파일을 별도 문서로 저장하되 parent_document_id로 원본 공지와 연결한다.
4. 표와 페이지 번호를 가능한 한 보존하고, 추출 실패 여부를 기록한다.
5. 검색 결과에는 첨부파일 내용과 함께 원본 공지 URL도 출처로 제공한다.

## 문서 선택 규칙 초안

1. 질문의 대상 학기·입학년도·학과와 일치하는 문서
2. 학칙·규정과 담당 부서의 공식 안내
3. 해당 학기의 공식 공지
4. 상시 학사안내 페이지
5. 학과 공식 페이지
6. 오래된 공식 문서

날짜만으로 우선순위를 정하지 않는다. 과거 입학자에게는 과거 기준과 경과조치가 현재 페이지보다 적합할 수 있다.

## 초기 평가 질문 15개

### 장학금

1. 2026학년도 1학기 세종가족장학금의 대상과 성적기준은 무엇인가?
2. 교내장학금과 다른 학비감면 장학금을 함께 받을 수 있는가?
3. 성적우수 장학금의 기본 선발 조건은 무엇인가?
4. 국가장학금 신청 시 재학생에게 적용되는 성적 기준은 무엇인가?
5. 장학금을 받은 뒤 휴학하면 반환해야 하는가?

### 수강·교육과정

6. 교양필수 과목의 이수구분이 변경되면 어떤 기준을 적용하는가?
7. 재수강할 수 있는 과목과 성적 처리 방식은 무엇인가?
8. 한 학기에 신청할 수 있는 최대 학점은 몇 학점인가?
9. 폐지된 교양필수 과목에 대체과목이 없으면 어떻게 되는가?
10. 복수전공 과목은 어떤 이수구분으로 인정되는가?

### 졸업요건

11. 2026학년도 소프트웨어학과 입학생의 졸업학점은 몇 학점인가?
12. 소프트웨어학과의 전공필수 이수요건은 무엇인가?
13. 영어졸업인증 대상과 면제 대상은 누구인가?
14. 편입생의 졸업요건은 신입생과 어떻게 다른가?
15. 입학 후 교육과정이 변경되면 어느 학년도의 졸업요건을 따라야 하는가?

질문 7, 8, 11~14는 최신 공식 자료를 추가 확보한 뒤 정답 근거를 확정한다.

## 확인된 위험

- 오래된 수강편람과 졸업 공지가 검색 결과에 노출된다.
- 상시 페이지와 학기별 공지의 조건이 다를 수 있다.
- 일부 과거 자료는 로그인 기반 시스템에서만 확인 가능할 수 있다.
- 표 추출이 깨지면 장학금명, 조건, 금액이 잘못 연결될 수 있다.
- 페이지 수정일과 규정의 실제 적용 시점이 같다고 단정할 수 없다.

## 최신성 검증 규칙

1. 퀵메뉴가 가리키는 단일 게시물을 최신 문서로 간주하지 않는다.
2. 게시판 목록과 페이지네이션을 순회해 후보 문서를 먼저 모두 수집한다.
3. 제목에서 학년도와 학기를 추출해 동일 문서군끼리 비교한다.
4. 같은 학기 후보가 여러 개면 게시일, articleNo, 첨부파일명과 해시를 비교한다.
5. 상세 페이지와 첨부파일까지 확인한 뒤에만 현재 사용 문서로 표시한다.
6. 판단이 불가능하면 두 문서를 모두 보존하고 review_status를 conflict로 설정한다.

## 자동 수집 정책 확인 (2026-08-09)

초기 조사에서 세종대학교 `robots.txt`는 일반 크롤러에 `Crawl-delay: 10`을 지정하고 `/*mode=download`, `/_attach/` 접근을 제한하는 것으로 확인됐다. 따라서 처음에는 첨부파일 자동 다운로드를 중단했다. 이후 사용자가 학교 측으로부터 개인 학습 목적 자동 다운로드 허가를 받았다고 전달했으며, 허가 조건인 요청 간 최소 10초를 지켜 공식 첨부파일을 수집했다.
