# 2021학년도 소프트웨어학과 필수 과목 구조화
> 현재 기준 안내(2026-08-10): 파이프라인 완성 후 전체 자동 테스트는 148개 통과했다. 본문에 더 작은 테스트 수가 있으면 해당 기능을 만들던 당시의 기록이다. 최신 전체 성능은 [독립 평가 보고서](HOLDOUT_EVALUATION.md)를 참고한다.


## 목적

PDF 표의 열이 평문 추출에서 섞이는 문제를 해결해 2021학년도 소프트웨어학과 단일전공자의 지정 교양선택 및 학문기초교양 과목을 과목명 단위로 답한다.

## 추출 방법

최신 `2026-2학기 수강편람_20260730.pdf`의 58쪽과 60쪽을 `pdftotext -bbox-layout`으로 추출했다. bbox는 bounding box의 줄임말이며 각 단어의 페이지 내 좌표를 뜻한다. 표 머리글의 소프트웨어학과 x좌표와 과목 행의 이수 학기 x좌표를 비교했다.

사람이 좌표를 대조한 결과는 `data/structured/graduation-requirements.json`에 출처 페이지, 공식 URL, 검증일, 추출 방법과 함께 저장한다. 이 레코드는 질문의 입학년도·학과·전공 형태가 모두 일치할 때만 Gemini 근거에 추가된다.

## 확정 결과

### 지정 교양선택

- 세계사:인간과문명 — 3학점, 2학년
- 고급프로그래밍입문-P — 3학점, 1학년 1학기
- Technical Writing 기초 — 2학점, 3학년 1학기

교양선택 전체 최소 이수학점은 폐지됐지만 학교 및 학과 지정 과목은 이수해야 한다.

### 학문기초교양

- 기초미적분학 — 3학점, 1학년 1학기
- 공업수학1 — 3학점, 1학년 2학기
- 통계학개론 — 3학점, 2학년 2학기

합계 9학점이며 61쪽 소프트웨어학과 학점표와 일치한다.

## RAG 연결

`graduation_requirements.py`가 검증 레코드를 찾아 공식 근거 청크로 변환한다. 생성 후 검증기는 여섯 과목 중 하나라도 답변에서 빠지면 1회 교정 생성을 요청하고, 다시 실패하면 답변을 출력하지 않는다.

최종 실제 질문:

`2021년 입학생이고 소프트웨어학과 단일전공이야. 졸업요건을 알려줘`

답변은 여섯 필수 과목, 교양필수 14학점, 학문기초 9학점, 전공 72학점(전필 36·전선 36), 총 130학점, 영어졸업인증과 고전독서인증을 포함했다.

자동 테스트: `122 passed`

## 한계

현재 좌표 검증이 끝난 구조화 레코드는 2021학년도 소프트웨어학과 단일전공 한 건이다. 다른 입학년도·학과·복수전공 질문은 구조화 데이터가 없으면 기존 문서 검색만 사용한다. 표 좌표 추출을 일반화한 뒤 다른 입학년도와 학과로 확대해야 한다.
