# 학교 허가 기반 첨부 자동 다운로드

## 허가 조건

2026-08-09 사용자가 학교 측에 문의한 결과, 개인 학습 목적의 크롤링 프로젝트에서 첨부파일 자동 다운로드를 허용받았다고 전달했다. 학교 측 요구 조건은 다운로드 요청 사이 10초 간격 준수다.

이 기록은 사용자가 전달한 허가 내용에 근거한다. 프로젝트는 허용 범위를 다음처럼 제한한다.

- 세종대학교 공식 학사·장학 공지 상세 HTML에서 발견한 첨부만 요청
- 공식 호스트, 허용 게시판 경로, `articleNo`, `attachNo` 일치 검사
- 실제 다운로드 요청 사이 최소 10초
- 로그인·개인정보·임의 URL 수집 제외
- 개인 학습 프로젝트 내부에서만 저장

## 안전장치

- 파일당 최대 200MiB
- 스트리밍 다운로드와 SHA-256 계산
- 완료 전 `.part` 파일 사용
- 실패 시 불완전 임시파일 삭제
- 첨부 ID 메타데이터가 있으면 재요청하지 않는 resume 동작
- 원래 파일명, 부모 공지, 공식 URL, MIME type, 크기, 해시 기록
- PDF·HWP·XLSX·DOCX·ZIP 실제 파일 서명 검증
