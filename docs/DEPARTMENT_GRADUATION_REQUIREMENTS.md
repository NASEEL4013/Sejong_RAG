# 학과별 입학년도 졸업요건 검색
> 현재 기준 안내(2026-08-10): 파이프라인 완성 후 전체 자동 테스트는 148개 통과했다. 본문에 더 작은 테스트 수가 있으면 해당 기능을 만들던 당시의 기록이다. 최신 전체 성능은 [독립 평가 보고서](HOLDOUT_EVALUATION.md)를 참고한다.


## 검증 질문

`2021년 입학생이고 소프트웨어학과 단일전공이야. 졸업요건을 알려줘`

## 문제와 해결

수강편람은 57쪽에서 2021학년도 구간이 시작되지만 소프트웨어학과 단일전공 학점표는 61쪽에 있어 해당 페이지 자체에는 2021학년도 문구가 없다. 검색기는 같은 파일에서 입학년도 제목부터 다음 입학년도 제목 전까지의 청크를 하나의 연도 구간으로 연결하도록 개선했다.

단일전공 졸업요건 질문에는 `단일전공 이수 시 학과별 졸업 이수학점` 표 제목을 검색 확장하고, 질문의 입학년도·학과·전공 형태와 모두 맞는 표를 우선한다. 표 행은 다음 여섯 필드로 구조화한다.

- 교양필수
- 학문기초교양
- 전공합계
- 전공필수
- 전공선택
- 졸업학점

생성 후 검증기는 여섯 값의 누락을 검사하며 `전공학점계`, `졸업이수학점` 같은 동의 표현은 허용한다. 같은 PDF 페이지가 여러 청크로 나뉜 경우 같은 페이지의 나머지 청크를 인접 페이지보다 먼저 문맥에 넣어 고전독서인증 누락을 해결했다.

## 확인된 결과

2021학년도 소프트웨어학과 단일전공:

- 교양필수 14학점, 8과목
- 학문기초교양 9학점
- 전공합계 72학점
- 전공필수 36학점
- 전공선택 36학점
- 졸업이수학점 130학점
- 영어졸업인증: 최신 전용 공지 기준 TEPS 301점 등
- 고전독서인증: 지정 도서 독서 및 검증시험 통과

근거는 최신 2026-2학기 수강편람 57쪽·61쪽과 2026년 영어졸업인증 전용 공지다.

자동 테스트: `118 passed`

## 남은 한계

58쪽과 60쪽의 학과별 지정교양·학문기초 과목 표는 PDF 텍스트에서 열이 평면화되어 있다. 현재 학점 합계는 구조화했지만 과목별 지정 여부는 아직 안전하게 구조화하지 않았다. 다음 단계에서 표 좌표 또는 별도 표 추출 방식으로 과목명 단위 요건을 검증해야 한다.
