# 2021학년도 입학생 졸업요건 질문 개선
> 현재 기준 안내(2026-08-10): 파이프라인 완성 후 전체 자동 테스트는 148개 통과했다. 본문에 더 작은 테스트 수가 있으면 해당 기능을 만들던 당시의 기록이다. 최신 전체 성능은 [독립 평가 보고서](HOLDOUT_EVALUATION.md)를 참고한다.


## 실패 증상

`2021년 입학생의 졸업요건을 알려줘` 질문에서 정확한 수강편람 대신 개인별 졸업심사 결과 명단이 상위 검색됐다. Gemini는 종합 수강편람의 과거 TEPS 556점과 최신 영어졸업인증 전용 공지의 301점 중 과거 값을 선택하거나 존재하지 않는 근거 번호를 생성하기도 했다.

## 원인

- 질문의 `2021년 입학생`과 문서의 `2021학년도 입학자 교과과정` 표현 불일치
- 졸업심사 명단의 많은 반복 텍스트가 벡터 검색을 점유
- 종합 편람과 최신 전용 공지의 수치 충돌
- LLM이 답변 범위와 인용 형식 지시를 항상 지키지는 않음

## 수정

- 입학년도 졸업요건 질문을 `{연도}학년도 입학자 교과과정 졸업 기준`으로 확장
- 일반 졸업요건 질문에서 졸업심사 결과 명단 강한 감점
- 입학년도·입학자·졸업·기준이 동시에 일치하는 표에 구조화된 보너스 적용
- 영어졸업인증 전용 공지도 함께 검색
- TEPS 301/556 충돌을 프로그램이 최신 전용 공지의 301로 해결
- 학과 미지정 시 학과별 예외를 제외하고 학과·전공 형태를 요청
- 생성 후 범위, 충돌 값, 인용 번호 검사 및 1회 교정 생성
- 유효하지 않은 복합 인용과 빈 목록 조각 정리

## 검증 결과

최종 실제 답변은 2021학년도 공통 기준, 130학점, 교양필수 8과목, 전공 형태별 기준, TEPS 301점과 G-TELP 65점을 공식 근거와 함께 안내하고 학과 및 단일·복수전공 여부를 요청했다. 개인 졸업심사 명단은 상위 결과와 생성 문맥에서 제외됐다.

자동 테스트: `111 passed`

이 숫자는 등록된 111개 자동 검사가 통과했다는 뜻이며 모든 졸업 질문의 정확도 100%를 뜻하지 않는다. 다른 입학년도와 학과 조합을 별도 holdout 평가에 추가해야 한다.
