# 정확도 우선 첨부·버전 정책

> 최신 확인: 2026-08-10. 이 문서는 현재 검색과 답변에 적용하는 기준이다.

## 첨부파일 정책

정확도를 우선하므로 공지에 첨부파일이 하나라도 있으면 내용 검토 전까지 `required`로 판정한다. `required`는 답변 근거가 들어 있을 가능성이 있어 반드시 수집해야 한다는 뜻이다. 신청서나 번역본처럼 보여도 파일명만 보고 제외하지 않는다.

학교 측에 개인 학습 목적의 자동 수집과 첨부파일 다운로드 허가를 확인했다. 모든 네트워크 요청 사이에는 최소 10초를 두고, 공식 세종대학교 도메인과 검증된 첨부 URL만 요청한다. 현재 2026년 학사·장학 공지 145건과 첨부파일 146개를 수집했다.

파일 중복은 URL이나 파일명만으로 판단하지 않는다. SHA-256(파일 내용으로 계산하는 고유한 요약값)과 추출한 내용을 함께 비교해야 같은 파일로 확정한다.

## 문서 버전 정책

과거 문서를 삭제하지 않는다. 어떤 문서를 우선할지는 질문의 시점에 따라 달라진다.

- 질문에 입학연도·학년도·학기가 있으면 그 시점에 적용되는 문서를 우선한다.
- “현재”, “이번 학기”처럼 현행 정보를 묻는다면 같은 문서군에서 학년도, 학기, 게시일 순으로 최신 후보를 선택한다.
- 과거 입학생의 졸업요건은 최신 수강편람으로 덮어쓰지 않고 해당 입학연도 규정을 사용한다.
- 소프트웨어학과와 2025년 이후 콘텐츠소프트웨어학과는 학과 명칭 변경 관계로 연결하되, 질문 시점의 공식 명칭도 함께 보존한다.

문서군은 같은 목적의 문서 묶음이다. 제목이 비슷하다는 이유만으로 다음 문서들을 한 묶음으로 처리하지 않는다.

- 일반 수강신청 / 특정 과목 수강신청
- 본교생의 타 대학 학점교류 / 타교생 학번 안내
- 장학금 신청 / 선발 결과 / 지급 안내

문서군이나 적용 시점의 확신도가 낮으면 `review_required`로 표시하고 자동으로 최신 문서라고 단정하지 않는다.

## 현재 검증 범위

- 2019~2026학년도 단일전공 졸업요건: 구조화 데이터 402행
- 2026년 학사·장학 공지: 145건
- 첨부파일: 146개
- 통합 청크: 14,054개
- 기본 답변에 사용하는 `trusted` 청크: 10,663개
- 추가 검토가 필요한 `review` 청크: 3,391개

`trusted`는 자동 검증을 통과해 기본 검색에 쓰는 자료이고, `review`는 OCR 오류나 구조 손실 가능성 때문에 기본 검색에서 제외하거나 신중히 사용하는 자료다.

## 최신성 검증 절차

1. 게시판 목록과 페이지를 순회해 후보를 빠뜨리지 않는다.
2. 제목·본문에서 학년도와 학기를 추출한다.
3. `articleNo`로 고정 공지와 검색 결과의 중복을 제거한다.
4. 상세 본문과 첨부파일을 모두 확인한다.
5. 같은 문서군 안에서 적용 시점과 게시일을 비교한다.
6. 충돌하거나 불명확한 자료는 모두 보존하고 검토 대상으로 분리한다.
7. 검색 평가와 Gemini 답변 평가로 변경 전후의 정확도를 확인한다.

## 남은 주의점

- 학교 규정의 실제 적용 대상이 문서 표현만으로 불명확할 수 있다.
- 공개 명단이나 연락처가 들어 있는 문서는 사용자 화면 공개 전에 개인정보 필터가 필요하다.
- `review` 자료가 꼭 필요한 질문은 자동으로 확정 답변을 내기보다 원문 확인을 안내해야 한다.
- 학교 사이트 구조나 정책이 바뀌면 자동 수집을 중단하고 다시 확인해야 한다.
