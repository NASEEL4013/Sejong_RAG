# OCR 원본 대조 및 활용 기준

## 검증 목적

OCR 신뢰도는 정답 정확도를 보장하지 않는다. 날짜, 금액, 학점, 신청 자격의 한 글자 오류도 잘못된 답변을 만들 수 있으므로 저신뢰 페이지를 원본 이미지와 직접 대조하고 OCR 문서의 인덱싱 기준을 결정했다.

## 검증 범위

- 전체 OCR: 6개 PDF, 57페이지
- 우선 검증: 평균 OCR 신뢰도 60 미만 7페이지 전부
- 원본 대조일: 2026-08-09
- 교정값: `eval/ocr_page_overrides.json`
- 적용 명령: `.venv/bin/sejong-validate-ocr`

## 발견 사항

- 저신뢰 7페이지 중 4페이지는 표지, 구분 또는 종료 화면이었다.
- 나머지 3페이지는 신청정보 확인과 홈페이지·모바일 서류 업로드 안내였다.
- 화면 캡처형 페이지에서 UI 아이콘과 작은 글자를 좌표 형태 숫자열로 오인한 사례가 있었다.
- PSM 11 재인식은 잡음을 줄였지만 원본 대조를 대체할 만큼 정확하지 않았다.
- 저신뢰 7페이지는 원본에서 직접 확인한 핵심 문구로 교체했다.
- 교정 레코드에는 `human_verified`, 검증일, 검증 이유와 원래 OCR 신뢰도를 함께 보존한다.

## 확정 활용 기준

1. `human_verified=true`인 OCR 페이지는 교정된 문구 범위에서 검색에 사용할 수 있다.
2. 검증하지 않은 OCR 페이지 50개는 후보 검색에는 사용할 수 있지만 확정 답변의 단독 근거로 사용하지 않는다.
3. 날짜, 금액, 학점, 신청 자격은 OCR 근거만으로 확정하지 않는다.
4. OCR 문서 6개는 문서 단위로 계속 `review_required`를 유지한다.
5. 첫 통합 인덱스는 `success` 문서 135개를 기본 대상으로 하고 검토 필요 11개는 별도 계층으로 격리한다.
6. 검토 문서를 사용해야 하는 질문은 공식 원본 링크와 검토 필요 경고를 답변에 표시한다.

## 직접 확인한 핵심 문구

- 국가장학금 신청정보 확인: 개인정보, 본인 소득·재산, 금융·신용·보험정보, 가구원 정보 제공 동의 확인
- 홈페이지 서류제출: 장학금 → 장학금신청 → 서류제출현황 → 서류제출
- 미혼 신청자: 부 또는 모 명의 가족관계증명서
- 기혼 신청자: 본인 명의 가족관계증명서
- 모바일 서류제출: 한국장학재단 앱의 장학금 → 장학금신청 → 서류제출 화면

이 검증은 저신뢰 페이지 전수검사이며 OCR 57페이지 전체의 전수 전사는 아니다.
