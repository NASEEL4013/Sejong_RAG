# 세종대학교 RAG

세종대학교 공식 공지와 첨부파일을 수집해 질문에 근거와 출처를 붙여 답하는 학습용 RAG 프로젝트입니다.

RAG(Retrieval-Augmented Generation, 검색 증강 생성)는 질문과 관련된 학교 자료를 먼저 검색한 뒤, 검색된 근거만 사용해 답변을 만드는 방식입니다. 학교 자료를 모델이 다시 학습하는 것이 아니라 수집·검색·답변의 세 단계를 연결합니다.

## 현재 상태

사용 화면을 만들기 직전 단계까지 완료했습니다. 기준일은 2026-08-10입니다.

| 항목 | 현재 결과 |
|---|---:|
| 2026년 학사·장학 공지 | 145건 |
| 다운로드한 첨부파일 | 146개 |
| 통합 검색 청크 | 14,054개 |
| 신뢰 사용 청크 / 검토 청크 | 10,663개 / 3,391개 |
| 2019~2026 단일전공 졸업요건 구조화 행 | 402개 |
| 독립 검색 평가 | Hit@5 1.0000, MRR 0.8646 |
| Gemini 답변 평가 | 32/32 통과 |
| 안전 행동 평가 | 4/4 통과 |
| 자동 테스트 | 148개 통과 |

`청크(chunk)`는 검색하기 좋은 크기로 나눈 문서 조각입니다. `Hit@5`는 정답 근거가 검색 결과 상위 5개 안에 포함된 비율이고, `MRR(Mean Reciprocal Rank, 평균 역순위)`은 정답이 검색 결과의 얼마나 앞쪽에 나오는지 나타내는 지표입니다.

소프트웨어학과는 2025년부터 콘텐츠소프트웨어학과로 명칭이 바뀐 것으로 처리하며, 검색에서는 두 명칭을 같은 학과의 연속된 이름으로 인식합니다.

## 처리 흐름

```text
세종대학교 공지 목록
  → 공지 본문·첨부파일 수집(요청 사이 10초 대기)
  → PDF/HWP/DOCX/XLSX 텍스트 추출 및 OCR
  → 문서를 청크로 분할하고 메타데이터 부착
  → 키워드 검색 + 임베딩 검색
  → 관련 근거 선별
  → Gemini가 근거 기반 답변과 출처 생성
```

OCR(Optical Character Recognition, 광학 문자 인식)은 이미지로 된 문서에서 글자를 읽는 기술입니다. 메타데이터는 공지 번호, 게시일, 문서 종류, 학년도처럼 문서의 정체와 적용 범위를 설명하는 부가 정보입니다.

## 처음 실행하기

Python 3.10 이상이 필요합니다.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e '.[dev]'
cp .env.example .env
```

`.venv`는 이 프로젝트 전용 Python 실행 환경입니다. 다른 프로젝트의 라이브러리 버전과 충돌하지 않게 분리합니다. `pyproject.toml`은 필요한 라이브러리, 실행 명령, 프로젝트 이름을 기록하는 설정 파일입니다.

`.env`에 Gemini API 키를 넣습니다. 이 파일은 비밀정보이므로 저장소에 공개하면 안 됩니다.

```dotenv
GEMINI_API_KEY=발급받은_API_키
```

질문은 다음처럼 실행합니다.

```bash
.venv/bin/python -m sejong_rag.ask_unified "2021년 소프트웨어학과 입학생의 졸업요건을 알려줘"
```

## 데이터 갱신 원칙

- 공식 세종대학교 공지만 수집합니다.
- 학교 측에 개인 학습 목적 자동 수집과 첨부파일 다운로드 허가를 확인했습니다.
- 서버 부담을 줄이기 위해 네트워크 요청 사이에 최소 10초를 둡니다.
- 첨부파일에 답변 근거가 있을 가능성이 있으면 생략하지 않습니다.
- 같은 종류의 문서는 학년도·학기·게시일을 비교해 질문에 맞는 최신 문서를 우선합니다.
- 과거 입학생 질문에는 최신 공지가 아니라 해당 입학연도의 규정을 우선합니다.

자세한 출처와 수집 정책은 [데이터 출처 문서](docs/DATA_SOURCES.md), 정확도 규칙은 [정확도·버전 정책](docs/ACCURACY_AND_VERSION_POLICY.md)을 참고하세요.

## 품질 확인

코드를 바꾼 뒤에는 다음 테스트를 실행합니다.

```bash
.venv/bin/python -m pytest -q
```

전체 검색 평가:

```bash
.venv/bin/python -m sejong_rag.evaluate_unified_retrieval
```

독립 평가 질문에 대한 Gemini 답변 평가:

```bash
.venv/bin/python -m sejong_rag.evaluate_unified_generation
```

독립 평가(holdout evaluation)는 검색 설정을 조정할 때 사용하지 않은 별도 질문으로 실제 일반화 성능을 확인하는 과정입니다. 결과 해석은 [독립 평가 보고서](docs/HOLDOUT_EVALUATION.md)에 정리했습니다.
